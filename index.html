Como pontuamos

O indicador automático usa P/VP (35 pontos), rendimento do informe (25), número de cotistas (10), patrimônio (10) e vacância (20 pontos quando aplicável). Dados ausentes não pontuam. Relatórios antigos reduzem a nota. Não é uma classificação de segurança, uma previsão nem uma recomendação de compra.

A nota é uma triagem automática, não previsão de retorno. Um P/VP baixo pode refletir problemas reais. Os riscos e notícias exigem leitura do relatório do administrador.

Origem dos dados

Para proventos recentes de alguns FIIs, há anúncios revisados com fontes e validade limitada. Para dados mais abrangentes e automáticos de proventos e vacância, o projeto aceita opcionalmente um token brapi Pro no GitHub Actions. Sem esse acesso, campos sem comprovação ficam como não confirmados, nunca preenchidos por suposição.

Estado das integrações

Atenção: você optou por priorizar FIIs sem reserva de emergência. A volatilidade pode obrigar a venda com prejuízo caso precise do dinheiro. Não invista capital essencial. Dados não constituem recomendação personalizada. Nenhuma transação é feita pelo aplicativo.
