Transparência antes de tudo

O radar só vale a pena se você souber de onde vêm os números e o que ainda falta verificar.

Como pontuamos

O índice usa P/VP (35 pontos), rendimento mensal informado no relatório (25), número de cotistas (10), patrimônio (10) e vacância (20 pontos, apenas para imóveis físicos quando disponível). Pesos ausentes não são inventados. Informe muito antigo reduz a nota.

A nota é uma triagem automática, não previsão de retorno. Um P/VP baixo pode refletir problemas reais. Os riscos e notícias exigem leitura do relatório do administrador.

Origem dos dados

Para datas de pagamentos confirmadas, vacância estruturada e valores exatos por cota de todos os FIIs, o projeto aceita opcionalmente um token brapi Pro no GitHub Actions. Sem esse acesso, campos sem comprovação ficam como não confirmados, nunca preenchidos por suposição.

Estado das integrações

Atenção: você optou por priorizar FIIs sem reserva de emergência. A volatilidade pode obrigar a venda com prejuízo caso precise do dinheiro. Não invista capital essencial. Dados não constituem recomendação personalizada. Nenhuma transação é feita pelo aplicativo.
